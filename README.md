## Alcance de la integridad

Los manifiestos A/B/C contienen metadatos y hashes, no conversaciones completas. Las raíces se pueden comprobar localmente con los scripts de cada carpeta y el verificador global. El comprobante OpenTimestamps está conservado; su presencia **no equivale a validación externa independiente del sello**.

**Exclusiones:** no se incluyen exports crudos, claves privadas ni las conversaciones originales completas.

**Visibilidad actual:** repositorio **privado**. El cambio a público se realizará separadamente; este traslado no modifica los permisos.
